# 🧠 سامانه جامع تشخیص هوشمند تومور مغزی (NeuroScan AI)
### Comprehensive Brain Tumor Detection, Malignancy Risk Scoring & CAD System

این مخزن شامل سامانه کامل تشخیص هوشمند تومور مغزی با استفاده از بینایی ماشین (**OpenCV 5.0**)، یادگیری عمیق (**PyTorch**)، هوش مصنوعی توجیه‌پذیر (**Grad-CAM**) و معماری کامل **تایپ‌اسکریپت (TypeScript)** است.

پروژه به دو بخش مجزا و مستقل تفکیک شده است:

---

## 🚀 راهنمای سریع اجرا

### اجرای سریع سامانه (پایتون + رابط کاربری رادیولوژی):
کافیست وارد پوشه `python-project` شده و دستور زیر را اجرا کنید:
```powershell
cd python-project
python server.py 8080
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **http://localhost:8080**

### مشاهده کدهای تایپ‌اسکریپت و بررسی تایپ‌ها:
```powershell
cd typescript-project
npm run type-check
```

برای مطالعه توضیحات کامل هر بخش، به فایل `README.md` موجود در داخل همان پوشه مراجعه فرمایید.
