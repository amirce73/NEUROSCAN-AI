# 🧠 سامانه هوش مصنوعی و بینایی ماشین تشخیص تومور مغزی (بخش پایتون)
### NeuroScan AI - Python Core Engine & Radiology Workstation

این پوشه شامل هسته پردازش تصویر، مدل‌های یادگیری عمیق، الگوریتم‌های تقطیع تومور، بیومارکرهای رادیومیک و وب‌سرور ایستگاه کاری رادیولوژی است.

---

## 🌟 ویژگی‌ها و ماژول‌های پروژه پایتون

1. **موتور بینایی ماشین OpenCV (`core/cv_engine.py`):**
   * **جداسازی خودکار مغز تک (`isolate_single_brain`):** تشخیص شیت‌های چند اسلایسی یا مقایسه‌ای و برش خودکار اسلایس اصلی حاوی تومور به ابعاد کالیبره‌شده 512×512.
   * **حذف خودکار استخوان جمجمه (Skull Stripping):** فیلتر دوجانبه، آستانه‌گیری و مورفولوژی کانتورها جهت ایزوله‌سازی پارانشیم مغز.
   * **تقویت کنتراست تطبیقی (CLAHE):** تفکیک دقیق مرزهای بافت نرم مغز از تومور.
   * **بیومارکرهای کمی:** مساحت ضایعه ($cm^2, mm^2$)، قطر معادل، گردی، یکپارچگی (Solidity)، موقعیت لوب مغزی و انحراف خط وسط مغز.

2. **مدل یادگیری عمیق و تخمین احتمال سرطان (`core/neuro_classifier.py`):**
   * شبکه عصبی عمیق کانولوشنی (PyTorch ConvNet) کالیبره‌شده با بیومارکرهای رادیومیک.
   * محاسبه درصد دقیق احتمال سرطان و بدخیمی ($0\% - 100\%$).
   * تعیین درجه سازمان بهداشت جهانی (WHO CNS Tumor Grade I-IV).
   * نقشه حرارتی بصری‌ساز **Grad-CAM (Explainable AI)** جهت نشان دادن دلایل تشخیص مدل.

3. **نمونه‌های بالینی استاندارد و واقعی (`core/sample_generator.py` و `samples/`):**
   * ۱۰ پرونده آماده جهت تست (شامل ۶ اسکن بالینی واقعی بیماران و ۴ نمونه بنچمارک کالیبره).
   * پشتیبانی کامل از آپلود و پردازش هر تصویر دلخواه.

4. **سرور و وب‌اپلیکیشن رادیولوژی (`server.py` و `web/`):**
   * سرور REST API چندنخی سریع پایتون.
   * ایستگاه کاری Dark OLED با پرتو اسکن لیزری متحرک، خط‌کش کولیس تعاملی ($mm$) و کارنامه رسمی رادیولوژی قابل چاپ.

## 📁 ساختار فایل‌ها

```
python-project/
├── core/
│   ├── __init__.py
│   ├── cv_engine.py           # پردازش تصویر OpenCV، حذف جمجمه و استخراج بیومارکرها
│   ├── neuro_classifier.py    # شبکه عصبی، تخمین سرطان و هیت‌مپ Grad-CAM
│   └── sample_generator.py    # پردازش و ثبت کیس‌های واقعی و بنچمارک
├── web/
│   ├── index.html             # اینترفیس ایستگاه کاری مدرن رادیولوژی
│   ├── styles.css             # تم دارک OLED ارگونومیک با افکت اسکن لیزری
│   └── app.js                 # منطق کلاینت و کنترل لایه‌ها
├── samples/                   # پرونده‌های سی‌تی اسکن و ام‌آر‌آی بالینی
├── tests/
│   ├── test_pipeline.py       # تست کامل پایپ‌لاین تشخیصی
│   └── test_server_api.py     # تست اندپوینت‌های وب‌سرویس
├── server.py                  # وب‌سرور HTTP و REST API
├── start.bat                  # اسکریپت اجرای تک‌کلیک در ویندوز
├── requirements.txt           # لیست پکیج‌های پایتون
└── README.md                  # راهنمای پروژه پایتون
```

## 🚀 نحوه اجرا

### ۱. اجرای آسان با اسکریپت ویندوز:
کافیست روی فایل `start.bat` دوبار کلیک کنید، یا در ترمینال دستور زیر را وارد نمایید:
```powershell
python server.py 8080
```
سپس مرورگر خود را باز کرده و به آدرس زیر مراجعه فرمایید:
```
http://localhost:8080
```

### ۲. اجرای تست‌های اعتبارسنجی خودکار:
```powershell
python tests\test_pipeline.py
python tests\test_server_api.py
```
